# Error codes

| Code | Meaning | What to do |
|------|---------|------------|
| E1024 | The motor is overheating. | Switch off and let it cool for 30 minutes. |
| E1042 | The pressure sensor reads out of range. | Replace the pressure sensor (part PS-12). |
| E2041 | The non-return valve does not close. | Check the valve seal for dirt or wear. |
